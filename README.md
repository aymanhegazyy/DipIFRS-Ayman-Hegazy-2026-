# 📚 DipIFRS Study Companion — December 2026

A complete, self-contained study platform for the ACCA Diploma in IFRS (DipIFR) exam, built as a single HTML file — works fully offline, no installation needed.

**🔗 Live site:** https://aymanhegazyy.github.io/DipIFRS-Ayman-Hegazy-2026-/

---

## ✨ What's inside

- **All 38 examinable standards** — IFRS, IAS, and other examinable documents, each with objectives, scope, worked examples, and exam-technique notes
- **Group Accounts bank** — 206 consolidation MCQs covering goodwill, NCI, fair value adjustments, impairment, associates, and disposals
- **Real Exam Bank** — 126 items sourced from real past ACCA DipIFR papers, organized by standard
- **🎯 Interactive Consolidation Practice** — 21 full real Question 1 consolidation exercises (SOFP & P&L), where you fill in every working line-by-line, get instant right/wrong feedback, hints, and a running score — built to mirror the real ACCA CBE exam screen
- **Flashcards, Formula Cheat Sheet, Buzzwords Ledger, Confused Standards** — quick-reference study tools
- **Full Mock Exam** and **Timed Mode** (60 min / 50 questions)
- **Progress tracking** — saved locally in your browser, no account needed

## 🚀 How to use

1. Open the live link above on any device (phone, tablet, laptop)
2. Everything works offline once loaded — no internet required after the first visit
3. Your progress is saved automatically in your browser's local storage

## 🛠️ Tech notes

- Single self-contained HTML file (vanilla JavaScript, no external dependencies, no build step)
- No backend, no database — everything runs client-side
- To update: edit `index.html` directly and push to `main`; GitHub Pages redeploys automatically
