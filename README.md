# 📚 DipIFR Study Companion

A complete, self-contained study platform for the ACCA Diploma in IFRS (DipIFR) exam — a single HTML file that works fully offline, no installation needed.

🔗 **Live site:** https://aymanhegazyy.github.io/DipIFRS-Ayman-Hegazy-2026-/

## ✨ What's inside

- All 38 examinable standards, each with objectives, scope, worked examples, and exam-technique notes
- A large, varied practice bank across many question formats (MCQ, True/False, Calculations, and more)
- Original interactive formats: Boss Fight, Decision Trees, Code Red, Investigation Cases, Exam Room
- Daily challenge mode with a streak tracker and milestone celebrations
- Review Center with progress tracking, weak-area detection, and a visual journey map
- Study Toolkit: exam technique guide, formulas, buzzwords, and glossary
- Dark Mode, Eye Protector mode, and printable per-standard PDFs
- Progress saved locally, with export/import between devices

## 🔜 Coming Soon

- Group Accounts / Consolidation practice module

## 🚀 How to use

Open the live link on any device. Works offline after the first visit. Progress saves automatically in your browser.

## 🛠️ Tech notes

Single self-contained HTML file, vanilla JavaScript, no backend, no build step.
